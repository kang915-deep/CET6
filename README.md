# CET-6 模考工作台

在线入口：https://kang915-deep.github.io/CET6/

- 18 套六级真题，包含原卷、听力音频、答案解析与 55 题自动判分。
- 原卷已逐页嵌入网页，支持翻页、页码跳转和 60%—200% 缩放；安卓平板无需系统 PDF 插件。
- 平板竖屏时试卷与答题区上下同屏，横屏或电脑端左右同屏。
- 听力 1—25 题支持逐题展开答案和文字解析。
- 自由练习可查看解析；整套模考交卷后解锁复盘。
- 作答与成绩只保存在当前浏览器，不会上传到服务器。

资料仅用于个人学习。原卷、音频与解析来源已在网页中注明；网络参考答案并非考试机构官方标准答案。
